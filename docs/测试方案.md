## 2. 测试环境与基建

### 2.1 环境

- 微信开发者工具 Stable 2.02.2608090，**游客模式**（`touristappid`）
- Node v18（跑 L1 单测与自动化脚本）
- 真机：iOS / Android 各 1 台（预览上传需测试号或正式 AppID）

### 2.2 已知坑（重要）

| 坑 | 规避方式 |
|----|----------|
| wechatide MCP 所有带 `--project` 的工具对 `touristappid` 报「不存在此 AppID」 | 自动化一律走原生 CLI：`cli.bat auto --project <路径> --auto-port 9420`（此命令不校验） |
| 游客登录凭证会过期（表现为开窗报 AppID 错误） | 退出工具→重新登录→登录窗口点「游客模式」 |
| Git Bash 调 CLI 必须带 `.cmd` 后缀 | 用 `wechatide.cmd` / `cli.bat` 全路径 |

### 2.3 分层策略（四层）

| 层 | 对象 | 工具 | 触发时机 |
|----|------|------|----------|
| **L1 纯逻辑单测** | utils（金额/streak/里程碑/券/roll 概率/迁移） | Node 直跑 `tests/unit.test.js`（mock wx 存储） | 每次改 utils、提交前 |
| **L2 页面自动化** | 六页渲染、数据绑定、交互、storage 副作用 | `miniprogram-automator` 连 9420 端口（`.verify/verify.js`） | 每次构建、改页面逻辑 |
| **L3 视觉验收** | 布局/遮挡/皮肤配色/动画帧 | `miniProgram.screenshot` 截图 → 逐张图像分析或人工 | 改样式/皮肤/动画后 |
| **L4 真机手工** | 触感、帧率、机型适配 | 真机预览 + 手工清单（§4.6） | 发版前 |

### 2.4 快速执行手册


## 3. 冒烟集（每次构建必跑，已自动化）

`verify.js` 已固化以下断言，任何一条失败即阻断：

1. 首页：初始数据（total=0、皮肤=redgold、里程碑 20 分钟 pct=0）
2. 抽烟页：进入态（showHint=true）、按住松开计 1 口、hint 消失
3. 烧完：结算卡出现、total=1、moneyText=¥1、inPack=1、按日聚合入库
4. 再戒一根：场景重置（showSettle=false、puffs=0）
5. 抽奖：凑满 20 根→开盒→reveal 出皮肤、券消耗（totalDraws=1）
6. 收下即换装：currentId 变为新皮肤
7. 收藏页：collected=2、tickets=0、draws=1、当前皮肤高亮
8. 统计页：total/streak/cells=30/milestones=8
9. 设置页：pricePerPack 默认值、quitDateStr 存在
10. 首页联动：换装后立绘数据随 currentId 变化
11. 全程 console error / exception = 0

## 4. 功能用例清单

优先级：P0 阻断核心闭环 ｜ P1 主流程 ｜ P2 边界 ｜ P3 体验。✅=已自动化。

### 4.1 抽烟会话（核心）

状态机：待机漂浮(未点燃) → 长按点火(1.2s 火焰粒子+烟头渐红) → 燃烧待吸(微光+青烟) → 按住吸(火光+震动+吸阻音+烟灰增长) → 松手吐烟 → 点按烟身抖灰 → 循环 → 燃尽(烟蒂弹飞) → 结算。

| ID | 用例 | 步骤 / 断言 | 优先级 |
|----|------|------------|--------|
| S-01 | ✅ 吸入/吐烟计口 | callMethod(onTouchStart/End) → puffs=1 | P0 |
| S-02 | **燃烧缩短回归**（曾出 bug：方向反了） | 按住截图 vs 初始截图：白色烟体变短、烟灰变长、燃烧线左移 | P0 |
| S-03 | 12 秒烧完 | 持续按住 BURN_MS → finish 自动触发 | P0 |
| S-04 | 结算入库 | settle.total 与 storage.total 一致、days 按日 +1 | P0 |
| S-05 | 结算前清场 | finish 时残留烟雾 0.5s 内散尽，结算卡无遮挡 | P1 |
| S-06 | 中途返回确认 | 已点燃未烧完时 onBack 弹 modal，取消留下/确认退出 | P1 |
| S-07 | 中途退出不计入 | 返回后 total 不变 | P0 |
| S-08 | 再戒一根 | 场景重置回待机态（未点燃），可再次完整流程（total 递增） | P1 |
| S-09 | 快速连按 | 连续 onTouchStart×N 不叠加燃烧（inhaling 守卫） | P2 |
| S-10 | touchcancel | 来电等中断等同 touchend（松开吐烟） | P1 |
| S-11 | 烧完瞬间再按 | finished 后 touchstart 无效 | P2 |
| S-12 | 凑满一包 | total%20===0 时结算卡出现「开盒」按钮 | P1 |
| S-13 | ✅ 待机漂浮态 | 进入页面 phase=idle、lit=false、burn=0，提示「长按点火」，烟支完整无火光 | P0 |
| S-14 | ✅ 长按点火 | 按住 0.7s：lightProg≈0.6 + 火焰粒子截图；按满 1.2s：lit=true、phase=burning；点火释放不计口 | P0 |
| S-15 | ✅ 点火中断退红 | 未点着松手 → phase 回 idle，红热 lightProg 渐退 | P1 |
| S-16 | ✅ 点按抖灰 | 吸入攒灰后 80ms 快速点按烟身（坐标取 getStats().geo）→ ashExtra=0、puffs 不变、烟灰粒子散落 | P0 |
| S-17 | ✅ 燃尽弹飞 | finish 后 0.45s 烟蒂带旋转/拖尾飞离画面（buttFly=true），结算卡 1.5s 弹出 | P0 |
| S-18 | 音效 | 点火播 lighter.wav、吸入播 inhale.wav；设置页关闭音效后静音 | P1 |
| S-19 | 提示分阶段 | idle→长按点火 / lighting→点火中… / burning 首口前→按住吸入·松开吐烟 / 首口后→点按烟身抖灰 | P2 |

**测试坑位记录**：模拟器里 100vh 解析为整屏高度（844），而 `wx.getWindowInfo().windowHeight` 是 671——点按烟身的坐标必须取 `getStats().geo` 暴露的真实画布几何，不能按 windowHeight 推算。
