# 戒一根 🚬

> 不求一辈子戒烟，只赢眼前这一根。

烟瘾上来时打开「戒一根」，点一根**虚拟烟**——按住吸入、松开吐烟，亲手把它抽完，这根真烟就算戒掉了。累计省钱、寿命和健康恢复；攒满一包还能**开盒抽烟盒皮肤**，还有低概率彩蛋等你撞见。娱乐壳 + 戒烟核。

微信小程序 · 原生开发 · 零 npm 依赖 · 无后端（本地存储）

---

## 玩法

**核心闭环**：点一根 → 按住吸入 / 松开吐烟（累计 12 秒烧完）→ 结算「第 N 根 · 戒掉了」→ 累计省钱 / 寿命 +11 分钟 / 根 → 攒满一包 20 根 → 开盒抽新烟盒。

**抽烟体验是一台完整的状态机**：

```
待机漂浮(未点燃) → 长按点火(打火机咔哒+火焰粒子+烟头渐红)
→ 燃烧待吸(余烬微光+青烟细缕) → 按住"吸"(火光爆亮+震动+吸阻音+烟灰增长)
→ 松手"吐烟"(烟雾团喷出) ★灵魂时刻 → 点按烟身"抖灰"(烟灰脱落)
→ 循环吸入…烟支逐渐变短 → 燃尽(烟灰坠落+烟蒂旋转弹飞) → 结算
```

**烟盒皮肤系统**：8+1 款纯 CSS 绘制的拟真风自造名烟盒（经典红金 / 软蓝天 / 薄荷爆珠 / 琥珀黄 / 黑冰 / 青山黛 / 紫气东来 / 鎏金岁月 + 隐藏款「彩虹」），普通 / 稀有 / 传说三档稀有度，可重复抽（×N 收藏角标）。选中烟盒后：首页立绘、抽烟页高斯模糊背景、烟支配色、烟雾颜色全部联动换装。

**低概率彩蛋**（概率集中在 `utils/eggs.js` 一处可调）：

| 彩蛋 | 触发 | 概率 |
|------|------|------|
| 趣味替身：棒棒糖 / 仙女棒 / 荧光棒 / 激光剑 / 香肠（各有专属画法、粒子与文案） | 进入抽烟页 | 2.5% |
| 心形烟圈：26 粒子沿心形曲线整圈上飘 | 每次吐烟 | 3% |
| 七彩烟：整根烟的烟雾彩虹色轮转 | 每根烟 | 4% |
| 隐藏皮肤碎片：烟蒂弹飞时掉落，集满 10 片解锁隐藏传说皮肤「彩虹」 | 每次燃尽 | 5% |

**数据与统计**：今日 / 累计省钱（按烟价折算）/ 寿命分钟（11 分钟/根）/ 连续戒断天数、本包进度、近 30 天热力图、8 档健康恢复时间线（20 分钟 → 1 年，已达成的点亮）。

**设置**：每包烟价、每日烟量基线、戒烟起点、音效开关、清空数据。

## 技术要点

- **动画**：抽烟场景 Canvas 2D 逐帧渲染（烟雾粒子物理 + 精灵图缓存 + 60fps 帧率限制器 + DPR 封顶 2）；UI 动画（开盒抖动翻牌、稀有度光效、结算卡）走 CSS keyframes
- **性能**：逐帧零内存分配（离屏 Canvas 预烘焙烟雾/火光贴图）、粒子数上限与离屏剔除、结算期间自动停掉 rAF 循环、模糊背景延迟淡入不占进场关键路径
- **烟盒**：纯 CSS（渐变盒身 + 盖线 + 花纹覆盖层 + 剪影模式），零图片资源，一套组件复用于立绘 / 收藏格 / 抽奖卡 / 模糊背景
- **音效**：`scripts/gen-audio.js` 用 Node 零依赖合成 WAV（打火机咔哒+whoosh、吸阻沙声，共 91KB），无需版权素材
- **图标**：`scripts/gen-icons.js` 手写 PNG 编码器（zlib）生成 tabBar 图标
- **存储**：全部本地（profile / days / total / skins / 碎片），无后端无登录

## 快速开始

1. 微信开发者工具 → 导入项目 → 选择本目录
2. AppID：仓库里的配置用的是测试号 AppID，可长期本地开发 + 真机预览；要发布请换成你自己注册的**小程序** AppID（注意：小游戏 AppID 不兼容本工程）
3. 编译即可在模拟器运行；真机扫码预览可在「预览」生成二维码

想重新生成资源：`node scripts/gen-icons.js`、`node scripts/gen-audio.js`。

## 坑位记录（踩过的坑）

- `canvas.requestAnimationFrame` 在开发者工具不受垂直同步限制（实测 180fps）——必须自建帧率限制器
- `wx:if` 切换 canvas 的兄弟节点会让 canvas 节点查询回调永不返回——延迟显示用 CSS animation 实现
- 模拟器里 `100vh` = 整屏高度，与 `windowHeight` 不一致——交互坐标以画布真实几何为准
- 模拟器自动化桥在异常断开后不恢复——测试前重开一次 `cli.bat auto` 即可
- `filter: blur` 在 Skyline 渲染器兼容性差——本项目固定 webview 渲染器
